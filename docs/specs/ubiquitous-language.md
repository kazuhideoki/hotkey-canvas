# HotkeyCanvas ユビキタス言語

## 1. 目的

- 開発者同士、および開発者とコーディングエージェントのコミュニケーションにおいて、同じ対象を同じ言葉で扱えるようにする。
- 実装都合の言葉ではなく、なるべく自然なドメインの言葉で会話できるようにする。
- `docs/specs/domain.md` に定義された実装上の概念と、日常的な会話で使う言葉の対応を明確にする。

## 2. 運用方針

- 会話、設計メモ、Issue、実装指示では、本書の推奨語を優先して使う。
- 1つの概念に対して複数の呼び方を持ち込まない。
- 実装名を会話に持ち込む必要がある場合でも、先にドメインの言葉で説明する。
- 新しい概念を導入した場合は、本書と `docs/specs/domain.md` を同じ変更で更新する。

## 3. キャンバス構造

### ノード

- 定義
  - キャンバス上の基本要素。
  - テキストや添付を持ち、他のノードと関係を持てる。
- 使い方
  - 「ノードを追加する」
  - 「フォーカス中のノードを削除する」
  - 「このノードに画像を添付する」
- 実装上の対応
  - `CanvasNode`
  - `CanvasNodeID`
- 非推奨
  - 要素
  - 箱
  - アイテム

### エッジ

- 定義
  - ノード同士をつなぐ関係。
  - 線の見た目を持つことはあるが、本質はノード間の関係である。
- 使い方
  - 「2つのノードをエッジでつなぐ」
  - 「このエッジを削除する」
  - 「エッジの向きを切り替える」
- 実装上の対応
  - `CanvasEdge`
  - `CanvasEdgeID`
- 非推奨
  - 線
  - リンク
  - コネクション

### 親

- 定義
  - あるノードに対して、上位側にあるノード。
  - 親子関係の基点となるノードを指す。
- 使い方
  - 「このノードの親をたどる」
  - 「親を持たないノード」
  - 「新しいノードを親の下に追加する」
- 実装上の対応
  - `CanvasEdgeRelationType.parentChild` による関係表現のうち親側のノード
- 非推奨
  - 上位ノード
  - 元ノード

### 子

- 定義
  - あるノードに対して、下位側にあるノード。
  - 親子関係において親にぶら下がるノードを指す。
- 使い方
  - 「子を持つノード」
  - 「子を横に並べる」
  - 「このノードを子として追加する」
- 実装上の対応
  - `CanvasEdgeRelationType.parentChild` による関係表現のうち子側のノード
- 非推奨
  - 配下ノード
  - 末端ノード

### 親子関係

- 定義
  - 2つのノードが、親と子として結ばれている関係。
  - ユビキタス言語では、まずノード同士の関係として扱う。
- 使い方
  - 「この2ノードは親子関係にある」
  - 「親子関係を作る」
  - 「親子関係を外す」
- 実装上の対応
  - `CanvasEdgeRelationType.parentChild`
- 非推奨
  - 親子エッジ
  - ツリー線

### フォーカス

- 定義
  - 今この瞬間に操作対象になっている単一の対象。
  - ノード、エッジ、エリアのいずれかを取りうる。
- 使い方
  - 「フォーカスを右のノードへ移す」
  - 「フォーカス中のエッジを削除する」
  - 「エリアにフォーカスする」
- 実装上の対応
  - `CanvasFocusedElement`
  - `focusedNodeID`
  - `CanvasEdgeFocus`
- 非推奨
  - カーソル
  - アクティブ項目
  - 現在選択中

### 選択

- 定義
  - 操作対象候補として保持されている状態。
  - 複数対象を含みうるため、フォーカスとは別概念として扱う。
- 使い方
  - 「複数ノードを選択する」
  - 「選択中のエッジをまとめて削除する」
  - 「フォーカス中のノードを選択に含める」
- 実装上の対応
  - `selectedNodeIDs`
  - `selectedEdgeIDs`
- 非推奨
  - ハイライト
  - アクティブ状態

### エリア

- 定義
  - キャンバス上で、特定のノード群に関連づくまとまり。
- 使い方
  - 「エリアにフォーカスする」
  - 「エリアの境界線の形を切り替える」
  - 「複数のエリアを縦に整列する」
- 実装上の対応
  - `CanvasArea`
  - `CanvasAreaID`
  - `CanvasNodeArea`
- 非推奨
  - 領域
  - グループ
